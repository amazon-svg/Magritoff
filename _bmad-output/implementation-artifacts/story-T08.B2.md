### Description fonctionnelle (Notion)

**En tant que** direction marketing/achats, **je veux** un mapping automatique des colonnes Excel vers les champs Magrit, avec profils réutilisables à chaque import, **afin de** ne pas refaire le mapping manuellement deux fois par an.
##### Critères d'acceptation
- Détection automatique des colonnes (SKU, libellé, catégorie, quantités, format, support, options, prix, fournisseur).
- Interface de correction pour les colonnes ambiguës.
- **Profils de mapping enregistrés** : chaque client définit une ou plusieurs templates de mapping, réutilisables.
- Mode « cleaning assisté par Marguerite » : pour fichiers exotiques (colonnes multiples, notes, images inline).
