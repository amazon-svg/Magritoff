## Description

Développer un plugin Magento qui enrichit le CMS existant sans le remplacer. Association produit Magrit → fiche produit Magento, transfert du panier. Approche « enrichissement » : Magrit s'intègre au CMS client sans rupture de l'existant.

## Critères d'acceptation

- Plugin installé sur instance Magento de test
- 3 produits Magrit synchronisés sur l'instance test sans remplacement du catalogue Magento existant
- Association produit Magrit → fiche Magento opérationnelle
- Transfert panier fonctionnel
