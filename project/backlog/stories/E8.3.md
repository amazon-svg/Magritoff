## Besoin utilisateur

**En tant qu'**utilisateur Pro, **je veux** voir un aperçu 2D / gabarit de mon produit après configuration, **afin de** valider visuellement avant commande.

## Critères d'acceptation

- Après configuration d'un produit, génération automatique d'un gabarit PDF technique (dimensions, bleed, marges, traits de coupe, zones sûres).
- Téléchargeable par l'utilisateur final.
- Réutilisable dans Canva via [T-07](https://www.notion.so/349d0131973c81f0b9defecf01cc783d).
- Paramètres exploitables par l'API publique (E5.1).

## Dépendances

- Moteur de gabarits Clariprint (E1)
- T-07 (Canva)
