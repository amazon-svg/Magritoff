## User story

En tant qu'imprimeur, je veux une vue de revue affichant le score de confiance par ligne, filtrable sur les lignes à valider (faible confiance, sans correspondance catalogue, ambiguës), avec édition avant chiffrage, afin de garder le contrôle tant que la normalisation n'est pas fiable à 100 %.

## Contexte

Façonnages exotiques, supports hors catalogue, combinatoires : un humain doit pouvoir corriger sans réimporter. Recoupe partiellement T08.B5 (détection anomalies).

## Critères d'acceptation

- Tableau React des `ao_line` avec confiance globale + flags ; tri/filtre par flag.
- Énum `flags` : `qty_unparsed`, `support_unknown`, `finishing_low_confidence`, `mapping_ambiguous`, `variant_overflow`, `no_catalog_match`.
- Édition inline → recalcul de confiance + persistance (`PATCH /api/ao/lines/{id}`).
- Validation d'une ligne lève ses flags et la rend chiffrable.
- Indicateur global « X lignes sur N à valider ».

## Specs API / Data

Front React/TS/Vite ; `PATCH /api/ao/lines/{id}`. Composant panneau testé via requête sémantique `find` (les portails React ne sont pas captés par `read_page filter:all`).
