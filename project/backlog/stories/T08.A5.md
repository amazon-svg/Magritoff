## Besoin utilisateur

**En tant que** direction achats, **je veux** un workflow de validation interne et un dossier d'attribution exportable, **afin de** documenter la décision pour audit (Sapin II, LSF, charte RSE).

## Critères d'acceptation

- Workflow : pré-sélection → validation N+1 → décision finale → motivation tracée.
- Dossier d'attribution : export PDF complet (cahier des charges, réponses anonymisées ou identifiées, critères, décision, signataires) utilisable en audit.
- Audit trail : toute action tracée et horodatée, signature électronique.
- Compatible politiques achats type Sapin II, chartes RSE groupe.

- Phase 2 (Q1 2027) : Module AO V1 — création + réponse + comparateur
- Phase 3 (Q2 2027) : Workflow validation + dossier d'attribution + audit complet
