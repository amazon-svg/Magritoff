# Domaines fonctionnels

Un document de domaine contient uniquement les principes fonctionnels transverses qui seraient inutilement répétés dans plusieurs fonctionnalités.

Chaque document reste `draft` jusqu'à approbation humaine et référence les décisions qui l'ont établi.

Les documents actuels sont des consolidations issues des PRD historiques et des décisions du 1er octobre 2026. Ils servent à préparer les epics et fonctionnalités, mais ne suffisent pas à déclarer une capacité approuvée ou livrée.
