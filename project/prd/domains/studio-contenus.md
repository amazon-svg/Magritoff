# Studio et contenus produit

## Finalité

Enrichir les produits et leurs supports commerciaux sans transformer Magrit en studio graphique généraliste.

## Principes provisoires

- générer du contenu marketing à partir d'un produit déjà calculé ;
- conserver la distinction entre données techniques, texte généré et visuel ;
- privilégier l'intégration d'outils spécialisés lorsque cela apporte plus de valeur qu'une fonction native ;
- réexaminer les spécifications du POC sur la version actuelle avant de créer un backlog actif.

## État

Le sujet Magrit Studio doit faire l'objet d'une revue fonctionnelle. Aucun ancien epic de connecteur design n'est réactivé automatiquement.
