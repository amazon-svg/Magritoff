# Boutiques B2B

## Finalité

Permettre à un imprimeur de proposer à ses clients un espace professionnel configuré, dans lequel ils retrouvent des produits, devis et commandes sans exposition de la complexité interne du système.

## Principes consolidés

- une boutique est rattachée à un espace et possède une identité visuelle configurable ;
- le catalogue publié reste distinct du catalogue source ;
- l'acheteur peut rechercher, configurer et renouveler un produit ;
- les données et permissions sont isolées entre boutiques et espaces ;
- les capacités commerciales peuvent être activées explicitement selon l'offre ;
- la nouvelle version du produit et le code livré prévalent sur les spécifications du POC pour constater l'existant.
