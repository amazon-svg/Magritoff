# PRD et principes produit

Ce dossier contient la vision, le périmètre et les principes produit consolidés au statut `draft`.

Les PRD historiques restent dans `_bmad-output/planning-artifacts/` comme provenances datées. Les éléments durables ont été reformulés ici ; les choix techniques périmés, anciens statuts de livraison et objectifs chiffrés non revalidés n'ont pas été reconduits.

Le PRD répond aux questions « pourquoi » et « quoi ». Les critères détaillés appartiennent aux stories ; les choix techniques appartiennent aux décisions d'architecture.

Les principes propres à un domaine sont placés dans [`domains/`](domains/).
