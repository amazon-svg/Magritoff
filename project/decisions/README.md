# Décisions

Une décision est séparée du compte rendu qui l'a motivée afin de rester identifiable et référençable. Son contenu n'est opposable qu'avec `documentStatus: approved` et `decisionStatus: adopted`.

Les décisions produit sont rangées dans `product/`, les choix structurants techniques dans `architecture/`. Les sujets non tranchés sont suivis dans `open-questions.md`.
