# Definition of Done

Une story peut être déclarée `verified` lorsque :

- l'implémentation respecte les critères approuvés ;
- les tests nécessaires sont ajoutés ou mis à jour ;
- les tests antérieurs invalidés ont été corrigés ou dépréciés avec justification ;
- les contrats et décisions techniques sont à jour ;
- les preuves d'exécution sont référencées ;
- les questions ouvertes restantes sont non bloquantes et visibles ;
- la revue est réalisée par une personne ou un agent distinct de l'auteur ;
- le statut du backlog et le document de livraison sont mis à jour ;
- aucun secret ni donnée personnelle inutile n'est introduit dans les documents.

`implemented` signifie que le code existe. `verified` signifie que les preuves attendues ont été obtenues. `released` signifie que la version concernée est effectivement livrée.
