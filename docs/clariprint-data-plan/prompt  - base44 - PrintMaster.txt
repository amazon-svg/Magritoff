### Onglet "Barème" :

Chaque poste de travail va contenir une liste de X barèmes de tarification

#### les fonctions
- Filtre :
	- par type de prestation
	- par type de support

- Tri :
	1/ type de prestation
	2/ type de support 1
	3/ format produit fini
	4/ nombre de pages min
	5/ nombre de postes
	6/ grammage support
	7/ épaisseur support
	8/ nombre de passe/tour
	9/ nombre d'exemplaire

- import/export XLSX
- nouveau barème

#### mode d'affichage 
- Affichage de la liste des barèmes sous forme de grille avec en-tête fixe et 2 premières colonnes
- Nouveau barème sous forme de fenetre modale

#### Structure d'un barème
{
##### condition obligatoire
	- type prestation : {
		type: selection simple
		enum : [
			Toute prestation,
			<liste des prestations pour le type de poste>
		 ]
	}

##### condition du support
	    - type de support 1 : {type: selection simple, enum : [vide, ... <types de support>]},
	    - ou type de support 2 : {type: selection simple, enum : [vide, ... <types de support>]},
	    - ou type de support 3 : {type: selection simple, enum : [vide, ... <types de support>]},
	    - grammage support min : {type:integer, unit:g/m2}, max : {type:integer, unit:g/m2},
	    - épaisseur support min : {type:integer, unit:micron}, max : {type:integer, unit:micron},
	    - largeur/laize min : {type:integer, unit:mm}, max : {type:integer, unit:mm},
	    - hauteur/coupe : {type:integer, unit:mm}, max : {type:integer, unit:mm},

##### condition du produit fini
	    - largeur produit fini min : {type:integer, unit:mm}, max : {type:integer, unit:mm},
	    - hauteur produit fini min : {type:integer, unit:mm}, max : {type:integer, unit:mm},
	    - epaisseur produit fini min : {type:integer, unit:mm}, max : {type:integer, unit:mm},
	    - nombre de pages min : {type:integer} max : {type:integer},
	    - nombre de postes à assembler min : {type:integer}, max : {type:integer},

##### condition quantitative
	    - nombre de passe/tour min : {type:integer} max : {type:integer},
	    - nombre d'exemplaire min : {type:integer} max : {type:integer},

##### coûts (UM = unité monétaire de l'imprimeur, exemples EUR)
	    - cout fixe (calage) : {type:float, unit:UM},
	    - cout au 1000ex : {type:float, unit:UM},
	    - limitation cadence : {type:float, unit:m/min}, 
	    - supp tx horaire : {type:float, unit:UM/h}, 
	    - supplément au m2 : {type:float, unit:UM/m2}, 

##### variation de coût en %
	    - majoration du coût au 1000ex : {type: float}
	    - variation de la cadence (>0 => augmentation, <0 => réduction) : {type: float}
	    - majoration du Tx horaire : {type: float}
	    - majoration du coût au m2 : {type: float}

##### gache
	    - gache fixe : {type: integer},
	    - gache de roule en % : {type: float},
}
